# Friends Poker V2

Pure entertainment Texas Hold'em for friends.

- 2–9 players
- Real-time Socket.IO multiplayer
- Blinds, pre-flop / flop / turn / river / showdown
- Fold / Check / Call / Raise / All-in
- 7-card hand evaluator and side-pot settlement
- Correct full-raise and short all-in reopening rules
- 25-second turn timer
- No deposits, withdrawals, or real-money exchange

Run the rule tests with:

```bash
npm test
```

Deploy with:
- Build: `npm install`
- Start: `npm start`
